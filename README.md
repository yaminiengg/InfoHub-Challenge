InfoHub-Challenge

InfoHub is a full-stack web application that provides real-time information on weather, currency conversion, and motivational quotes. Built using React for the frontend and Express + SQLite for the backend.

Features

Weather Information: Get real-time weather updates for any city using the OpenWeatherMap API.

Currency Converter: Convert INR to USD and EUR using the ExchangeRate API.

Quote Generator: Fetch inspirational quotes from the ZenQuotes API.

Responsive Design: Fully responsive UI with card-based layout.

Database Storage: Stores weather history in SQLite database for analysis.

Tech Stack

Frontend: React, CSS

Backend: Node.js, Express

Database: SQLite

APIs: OpenWeatherMap, ExchangeRate-API, ZenQuotes
